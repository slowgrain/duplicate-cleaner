# Slowgrain Duplicate Cleaner — 설치 파일

PC와 Google Drive의 똑같은 파일, 비슷한 사진·영상을 찾아 정리하고, 남은 사진을 촬영일·장소별 폴더로 나눠 주는 Windows·Mac 앱입니다. 이 저장소에는 **설치 파일만** 있습니다(소스 코드는 없습니다).

- **받기:** 오른쪽 [Releases](../../releases/latest)에서 운영체제에 맞는 파일을 받습니다.
  - Windows 10·11: `Slowgrain-Duplicate-Cleaner-Setup-<버전>-win-x64.exe`
  - Apple Silicon Mac(M1 이후), macOS 13 이상: `Slowgrain-Duplicate-Cleaner-<버전>-mac-arm64.dmg`
- **무료 검사판:** 키 없이 설치하면 모든 검사와 결과 보기, 미리 보기를 할 수 있습니다.
- **정식판:** 구매한 키를 처음 실행할 때 뜨는 창(또는 앱 왼쪽 아래 '키 입력')에 넣으면 구매한 정리 기능이 열립니다.
- 제품 소개·가격·약관·개인정보처리방침·환불 정책: https://moraonstudio.com/slowgrain/duplicate-cleaner/ko/
- 설치할 때 경고가 뜨는 이유와 허용 방법은 제품 페이지의 설치 안내를 봐 주세요(개인 개발 프로그램이라 코드 서명이 없습니다).
- 각 릴리스에는 파일별 SHA-256과 VirusTotal 검사 결과 링크가 있습니다.
